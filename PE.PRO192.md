| Đề PE             | Code                              |
| ----------------- | --------------------------------- |
| first             | `charAt(0)` hoặc `substring(0,1)` |
| last              | `substring(length-n)`             |
| remove first      | `substring(1)`                    |
| remove last       | `substring(0,length-1)`           |
| insert đầu        | `"CF"+name`                       |
| insert cuối       | `name+"CF"`                       |
| lowercase         | `Character.toLowerCase()`         |
| uppercase         | `Character.toUpperCase()`         |
| contains digit    | `Character.isDigit()`             |
| contains letter   | `Character.isLetter()`            |
| length            | `name.length()`                   |
| format 2 decimals | `String.format("%.2f", value)`    |
| toString          | Nối chuỗi bằng `+`                |
